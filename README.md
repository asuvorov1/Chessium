# ♞ Chessium

Анализ шахматной партии в стиле chess.com прямо поверх сайта. Chessium сам находит доску на экране,
распознаёт позицию, следит за ходами и анализирует их через [chess-api.com](https://chess-api.com) (Stockfish).

## Установка
Скачайте `Chessium-Setup-x.y.z.exe` со страницы [Releases](https://github.com/asuvorov1/Chessium/releases) и запустите его.
Права администратора не нужны. Есть и portable-версия: архив `Chessium-x.y.z-portable.zip`, распакуйте и запустите `Chessium.exe`.

Требования: Windows 10 (2004+) или 11, x64, интернет.

## Как пользоваться
Откройте партию на chess.com или lichess и запустите Chessium. Настраивать ничего не нужно:
- доска находится автоматически (кнопка ⌖ запускает поиск заново);
- анализ начинается с любой позиции, начальная расстановка не нужна;
- окно программы и стрелки на сайте скрыты от снимков экрана, поэтому распознаванию не мешают.

## Возможности
- **Автопоиск доски** на всех мониторах. Если доска сдвинулась или пропала, Chessium ищет её снова.
- **Распознавание без калибровки** по шаблонам популярных наборов фигур chess.com и lichess. Затем программа дообучается на вашей теме доски.
- **Шкала оценки, до 5 линий движка, лучший ход** — стрелкой в окне и на доске сайта.
- **Оценка каждого хода**: блестящий, отличный, лучший, превосходный, хороший, теория,
  неточность, ошибка, промах, зевок. Значок хода появляется и на доске сайта.
- **Отчёт**: точность белых и чёрных, сколько ходов каждого типа.
- **График оценки, список ходов, название дебюта**.
- Навигация по ходам: кнопки или стрелки ← → Home End.
- Меню ⋮: линии и глубина, ориентация доски, смена очереди хода, ручное выделение доски,
  компактный режим, копирование FEN/PGN, открытие позиции в Lichess.

Данные программы (настройки, лог, выученные темы) хранятся в `%LOCALAPPDATA%\Chessium`.
Если что-то пошло не так, загляните в `chessium.log` в этой папке (меню ⋮ → «Открыть папку данных»).

## Запуск из исходников
```
pip install -r requirements.txt
python app.py
```

## Сборка exe и установщика
Нужны Python 3.11+ и [Inno Setup 6](https://jrsoftware.org/isinfo.php) (`winget install JRSoftware.InnoSetup`):
```
powershell -ExecutionPolicy Bypass -File build.ps1
```
Результат появится в папке `dist/`: `Chessium-Setup-x.y.z.exe` и `Chessium-x.y.z-portable.zip`.

## Устройство
| Файл | Что делает |
|---|---|
| `app.py` | главное окно, слежение за доской, слой со стрелками поверх сайта |
| `board_finder.py` | поиск доски на скриншоте (сетка 8×8 по линиям перепада яркости) |
| `recognizer.py` | распознавание фигур по силуэтам и самообучение |
| `pieceset.py` | наборы фигур для шаблонов (встроенный cburnett и загружаемые) |
| `game.py` | отслеживание ходов, оценка ходов, точность, дебюты |
| `engine_api.py` | клиент chess-api.com (WebSocket с несколькими линиями, POST как запасной вариант) |
| `ui.py` | виджеты интерфейса |

## Сторонние материалы
- Изображения фигур chess.com и lichess **не входят** в репозиторий и установщик:
  программа скачивает их при первом запуске для локального распознавания.
  Встроенный набор cburnett взят из [python-chess](https://github.com/niklasf/python-chess).
- База дебютов — [lichess-org/chess-openings](https://github.com/lichess-org/chess-openings) (CC0).
- Анализ — [chess-api.com](https://chess-api.com) (Stockfish).

## Fair play
Используйте Chessium для разбора партий, задач и трансляций. Подсказки движка во время рейтинговых партий
нарушают правила chess.com и lichess, за это банят аккаунты.
